# 技术方案阅读版评测

维护人：Compass 项目维护者。命令从项目根执行，依赖准备见[生成说明](../references/generation.md)。

```bash
npm test --prefix .agents/skill/my-design-to-html
```

自动评测在系统临时目录生成另一业务领域的文档，核对源文件不变、代码提取、离线交互、SVG 与 Mermaid、重复图的 ID、异常时保留旧产物和独立路径运行。实际测试结果以本次命令输出为准。

## 内容行为用例

输入 [source.md](source.md) 是包含目标、核心算法、验收、部署与评审章节的合成报表方案。[guide.md](guide.md) 是依内容契约整理的基线阅读稿，[edition.json](edition.json) 是可运行配置。

| 用例         | 请求与输入                                       | 期望                                                                                              |
| ------------ | ------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| 默认阅读版   | “把 source.md 做成人工 review 的 HTML。”         | 目标表三列居首；保留 500 行、3 个字段和 CSV；省略工作流章节；核心算法完整；无课次 13 的参数与名称 |
| 无量化目标   | 源方案只有查询页面的标题修改，未给性能指标       | 指标写“未设定”；使用目标表、对比或文件清单即可，无新增 SLA、ER 或复杂流程                         |
| 关键机制     | 源方案涉及重试、取消或并发限制，用户希望只看设计 | 保留对应设计规则和关键分支，省略部署/测试手册                                                     |
| 指定保留内容 | 用户明确要求加入兼容性对比表                     | 保留所要求的对比表，遵从本次用户范围                                                              |
| 更新附录     | 已有阅读稿，原代码附录新增一个关键分支           | 重新引用完整代码；选择器多匹配时提示核对，不静默选择旧块                                          |
| 独立移交     | 把 HTML 单独复制到空目录并断网打开               | 图、代码、搜索、放大、复制可用；无旁边文件依赖                                                    |

内容行为评测需要实际执行 Skill 并审读产物。自动测试覆盖生成器行为，无法单独判定语言模型是否正确裁剪原方案。手工复核时每项按“通过 / 未通过 / 不适用”记录，不把未执行用例计为通过。

## Rubric

| 维度       | 通过条件                                                           |
| ---------- | ------------------------------------------------------------------ |
| 内容忠实   | 字段、数字、所有权、状态与关键代码符合当前输入；未设计内容保持缺口 |
| 阅读结构   | 目标在首位；图表、代码与文件清单占主体；无重复长篇解释             |
| 密度与视觉 | 三列表可读；图内文字清楚；代码保留缩进和完整分支；窄屏可滚动       |
| 使用体验   | 离线独立阅读、搜索、代码复制/展开、图表缩放/导出和打印可用         |
| 工作边界   | 原方案与业务代码保持；无自动评审结论、部署、发布或阶段推进         |

以上适用项全部通过后完成评测。任何脚本或模板行为改动须运行自动评测，内容规则改动另复核相应行为用例。截图与临时产物放在 `work/` 或系统临时目录，不放入此目录。
