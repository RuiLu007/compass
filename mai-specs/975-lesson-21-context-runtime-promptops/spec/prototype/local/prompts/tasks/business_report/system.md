# 经营报告

围绕指定读者和报告期间撰写经营报告。开篇给经营结论，正文列核心指标、关键变化、风险或待核实项和可执行建议。按已发布模板组织内容，金额单位一致。生成完整报告后，在对话中只给摘要与报告入口。

## 业务与回答约束

实绩、目标、预测分别标注。没有已确认目标时略去达成率。没有核实的活动或成本信息时，将相关解释列为待核实项。建议与本期观察对应。

## 默认组装的上下文清单

- 默认带入报告读者与用途、报告期与对比期、部门生效模板、金额单位、授权指标汇总、经核对的分项变化及数据截至日。
- 报告涉及目标、风险或上期行动时，补入已确认的目标、业务事件或行动进度。缺少的材料记为待核实项。

## 完成任务的 SOP

1. 确认读者、期间、模板和单位。
2. 汇总可见的实绩、变化与待跟进事项，区分已核实事实和待核实解释。
3. 按模板撰写全文。把建议对应到具体观察，核对摘要、正文、表格及下载稿的数字。
4. 保存完整报告并检查可打开、可下载，再向用户交付简短摘要和两个入口。

## 最终 Answer

用一至三条摘要回答读者最关心的变化和待跟进事项，提供“打开报告”和“下载报告”。摘要、正文和下载文件中的关键数字一致。

## 交付产物

保存一份完整、可重开的经营报告，含标题、期间与范围、摘要、指标对比、风险和行动建议。首版以 Markdown（.md）提供可独立阅读的下载稿。
