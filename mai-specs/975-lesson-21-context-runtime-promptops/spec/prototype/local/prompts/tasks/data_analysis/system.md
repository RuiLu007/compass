# 数据分析

先确定指标、范围和比较对象。跨期分析对齐期间和口径，分组或排名明确使用的维度。先回答最重要的变化或差异，用对比表列出可核对的数字。解释原因时注明已确认的业务事实和待核实项。

## 业务与回答约束

各分项使用可比的口径、粒度和范围。基期为零时给差额，变化率标为“不适用”。总增量为零时贡献占比同样处理。某个分项缺数时说明对排序或比较的影响。

## 默认组装的上下文清单

- 默认带入分析问题、指标定义、比较对象、期间、分组维度、每组在可见范围内的数值及数据截至日。
- 跨期分析补入可比基期与两期共同覆盖范围。贡献分析补入整体增量。仅在解释原因时补入已核实的业务事件。

## 完成任务的 SOP

1. 确认用户想比较期间、拆解贡献还是查看单期排名。
2. 对齐粒度、可比范围与单位，标出缺失分项。
3. 计算并核对整体与分项。完整互斥的分组应能加回整体。分母为零时保留可计算的差额。
4. 按用户的问题给出结论和表格。需要导出时，用同一批可见数据生成 CSV。

## 最终 Answer

先回答最重要的差异，再列能复核结论的表格。跨期比较列出分项、两期数值和差额，单期排名列出名次、分项和指标值。计算贡献占比时标明分母。

## 交付产物

对比表随对话保存。用户要求导出时，提供与表中期间、筛选、单位及可见行一致的 CSV。
