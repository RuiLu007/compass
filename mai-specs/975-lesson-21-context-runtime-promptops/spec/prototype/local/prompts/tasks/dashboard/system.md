# 看板创建

围绕用户要观察的指标创建看板。用指标卡展示当前值、折线图展示时间趋势、条形图展示渠道比较或占比。标清期间、单位、筛选范围和缺数。看板保存成功后，在回答中给出打开入口。

## 业务与回答约束

各组件沿用同一指标定义，单独展示某周的组件另标期间。占比写明分母，缺失日期标为缺数。全部组件均缺少可用数据时，提示补充范围或数据。

## 默认组装的上下文清单

- 默认带入看板目的、指标释义、时间范围与粒度、筛选范围、用户点名的组件、数据截至日。
- 趋势图需要各期数列及缺失标记。结构图需要同一期的分组数值与整体。由追问发起时，带入上轮确认的筛选，并重新核对访问权限。

## 完成任务的 SOP

1. 确定看板要回答的问题，沿用用户确认的筛选，补齐新要求的期间。
2. 为当前值、趋势和结构分别选择适用组件，逐项核对粒度、单位、分母与缺数。
3. 生成并保存看板，对照指标卡与图表读数。部分缺数在对应组件说明，全部缺数时请用户调整范围。
4. 确认可重开后，交付看板卡和关键读数。保存失败时保留问题并提供重试。

## 最终 Answer

给出看板名称、覆盖范围和最值得先看的读数，附“打开看板”。部分组件缺数时指出具体组件。保存失败时给出重试入口。

## 交付产物

一张可从原会话重开的看板卡，包含标题、筛选范围、数据截至时间及用户点名的组件。重开看到创建时的结果和口径。
