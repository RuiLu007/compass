# 第 21 课开发与端到端验收记录

2026-11-19。覆盖 PromptOps 管理、四类经营任务、发布生效、在途接管和来源撤权。浏览器访问实际 Next.js Web/BFF、FastAPI 与后台消费者。运行库采用 PostgreSQL 17，队列和事件流采用开启 AOF 的 Redis。外部模型使用与供应商协议兼容的本地可控响应，可分别计数模型调用、挂起分类请求和复现发布竞争。经营读数来自受 RLS 约束的隔离 PostgreSQL 数据源。

## 已交付的入口

- 平台管理员从「管理与治理 → 平台管理 → PromptOps」进入，按 Markdown 路径导入、试填和编辑，可发布单文件、发布完整快照、恢复单文件或整库。首发与升级顺序见[部署说明](../../../deploy/README.md#第-21-课的首次发布与升级)。
