# 工具目录与统一注册实施记录

2026-11-14，验收范围见 [技术方案](design/TECH_DESIGN.md)。

## 实现

- 16 个静态工具按工具名独立目录：6 个通用工具、10 个业务工具。
- `tools/catalog.py` 维护唯一静态清单；每个目录的 SPEC 管定义、启用、并行和执行适配。Runtime 预检、主任务及工作流子任务复用声明与注册。
- 通用 Todo 状态与依赖转换移入 builtin；Retail 适配保留日期、目标、查询匹配和完成核验。通用 Todo 支持无 Retail 的 Agent。
- Python 使用独立能力组，沙箱可用即可注册；owner、Run、输入大小和清理规则保留。
- 工作流工具的参数和执行适配、周复盘构建、数据库发布分别归入工具目录；共享工作流引擎保留编排、收据和资产状态。
- 迁移源码、脚本及测试的 Python 导入同步更新。无数据库结构或 HTTP 契约变更。
