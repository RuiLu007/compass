通用 Agent Runtime

用统一运行内核承接不同任务，通过提示词、工具与 Skill 装配能力。

执行主链路模块与配置运行约束

执行主链路

Runtime 装配当前 Agent 的定义与工具，路由决定模型和确定性任务路径，所有生成与工具调用复用 Harness 和工具 Dispatcher。

模块与配置

@dataclass(frozen=True, slots=True)
class AgentDefinition:
    system_prompt: str = SYSTEM_PROMPT
    tools: tuple[RegisteredTool, ...] = ()
    builtin_tools: frozenset[str] = frozenset()

应用显式装配内置能力，也可以只提供自定义提示词和工具。模型输入使用已冻结的工具目录，工具结果按模型调用顺序回填。 

+ harness/context.py、prompts.py：定义、上下文、系统指令
! harness/executor.py：统一工具循环
+ routing/workflows.py：确定性任务与日期解析
+ runtime/service.py、turn.py、tool_bindings.py：运行装配
+ tools/builtin/retail/plan.py、verifier.py、session.py、actions.py
- analysis/ 与未使用的空目录

运行约束

保留工具参数与权限校验、批次策略、预算、取消和清理规则。动态 Workflow、Skill、审批与 Worker 接续仍经过现有持久执行边界。

固定课堂问题和日期从生产链路移除。工作流参数来自本次请求；缺少日期返回 period_required。HTTP 路径与持久 DTO 保持兼容。
