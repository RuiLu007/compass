迁移顺序

  1. 建立规范与默认清单、导入、打包边界。
  2. 先抽离授权连接，打通 SQL → Python 通路。
  3. 删除固定零售与周报工具，案例改为普通提问。
  4. 同步公开契约，处理旧请求、活动 Run 与旧工作流。
  5. 验收查询、计算、缺口、权限、取消及持久恢复。

切换前完成或明确取消受影响的旧 Run；保留用户数据和迁移历史。HTML 文件产物另列切片，需要独立设计类型约束、下载与隔离预览。
