## 课堂使用

1. 按根 README 准备正常 Web/Agent 环境，执行 `pnpm db:migrate -F agent` 升级至 0004，生成/构建后启动两端。
2. 平台管理员进入“Agent 与模型”页 `/platform/models`，找到“可靠性模拟测试”。无需新增 Provider 或填写模型密钥；Agent 服务令牌仍按现有配置提供。
3. 推荐演示顺序：429 后恢复 → 认证失败 → 输出半途断流 → Schema 拦截 → 已发送后超时 → 取消 → 并发过载 → 关闭失败隔离。
4. 观察实时供应商请求/返回事件、Attempt 1/2、输出预览、提交数、未知用量、活跃/逻辑峰值及可用/隔离槽。“场景符合预期”根据真实执行结果计算；故障场景的调用失败可符合演示预期。
5. “停止演示”取消当前根任务及子执行；先前片段仅供预览。每场使用独立 Gate，关闭失败隔离不会消耗普通模型调用容量。

日常连接及数据未迁移或重置。本次验收预览服务使用独立测试库；不要将其测试 Provider 当作日常模型配置。上课使用自己的平台账号及正常应用启动入口。

- R1 已落实：路由主生成显式两次，Flash/JEV 分类各一次；两类 envelope、派生 ID、父期限及真实 HTTP 根 runner 均保留并验证。
