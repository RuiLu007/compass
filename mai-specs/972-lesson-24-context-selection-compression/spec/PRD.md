# PRD｜第 24 课｜动态上下文选择与压缩

## 用户与业务流程

经营分析师问“上月净销售额为何下降”。SQL 步骤需要指标公式、字段与关联键；归因步骤需要互相印证或冲突的结果；报告步骤需要保留关键数字及其出处。

先用权限和必保项建立规则基线，再按任务和模型调整预算。检索候选由第 23 课提供。

## 功能范围与验收场景

### 候选与准入

统一接收 Prompt、语义定义、证据、工具结果、摘要和运行状态，登记来源、版本、权限和 Token。过滤未授权或已失效的项，再锁定当前任务必需的约束。

**AC-01**　给同一步骤混入跨租户证据和低相似度的必需公式，装配结果排除前者、保留公式，并记录原因。

### 排序与预算

按相关性、必要性、可信度、新鲜度、重复度和长度选择候选。按 SQL、归因、报告分别分配系统、任务、历史、工具、证据和输出预算。必保项超限时返回缺口，交由调用方缩小任务或补证。

**AC-02**　缩小同一 SQL 任务的窗口，逐项核对预算、输出预留、关联键和指标口径；必保项无法容纳时调用停在装配阶段。

### 压缩与校验

分别支持抽取片段、阶段摘要和结构化数值；大型结果保留 Artifact 引用。装配前核对数值、单位、公式、约束及引用，失败时回取原文或请求补证。

**AC-03**　压缩含冲突数值的两份证据，核对各自时间范围与来源；改动一个单位后应触发校验，并可定位原文。

### 策略实验

固定三类任务、候选和模型，比较规则、Embedding、Reranker 与决策模型，分别切换压缩方式、稳定前缀与排列顺序。

**AC-04**　与完整授权上下文基线逐题比较 SQL 结果、归因证据与报告事实。报告输入 Token、缓存命中、端到端时延及含选择和压缩调用的总成本；质量退化的组合保留为实验。

## 评审待定

按三类任务实测基线后确定 Token 节省目标与时延上限。
