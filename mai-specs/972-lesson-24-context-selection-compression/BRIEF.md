## 一句话描述

让 Agent 在短会话按序工作，在大型工具结果中按需读原件，并能在窗口接近水位时交接长历史。

## 背景

第 23 课检索返回多个候选，模型窗口需要容纳必要口径、证据和输出。

## 关键决策

在已有 Context Runtime 上，大工具结果先存文件，再将摘要、样本与索引加入消息。普通轮次顺序追加；历史达到轮数或容量条件时，JEV 按当前问题判断较早完整轮的 keep / drop，保护最近 3 轮。选择后仍达到水位才剪枝并摘要本次保留的历史。保留系统与内置上下文，按 token 预算回填最近完整轮。
