## 主要实现

- `runtime/{store,entities,journal,durable_service,redis_stream,message_reader}.py` 管理持久事实、单实例执行权、Checkpoint、Outbox 与短期流；`api/sessions.py` 提供 Message/Run v2 入口，v1 通过适配器保留原有合同。
- `models/attempts.py` 在每次物理派发前记录输入及预算预留，保存输出、清理与未知结果；模型内容和续接权限分别按用途加密。
- `runtime/{hitl,commands,resources}.py` 管理版本化决定、唯一效果、可信外部事件、产物原字节和保存邀请。审批期限采用 PostgreSQL 时钟。
- Web BFF 保持身份/范围/CSRF 和响应运行时校验；分析页用同一 reducer 处理实时增量与完整历史，补齐会话分页、刷新、审批、恢复和原文件下载。
- 迁移真源为 `apps/agent/migrations/versions/0009_durable_runs.py`；SQL、manifest 由数据库工具生成，交付所有历史起点到 0009 的路径。部署增加持久 Redis，并将基础服务启动纳入根部署编排。
- 使用说明见 [持久运行说明](../../docs/lesson-19-durable-runtime.md)。配置、CI、应用 README 与 UI 规范已同步。
