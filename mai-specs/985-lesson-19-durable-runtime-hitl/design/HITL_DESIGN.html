等待、接续与取消

批准与取消共用行锁裁决；实际效果提交前再次检查取消和执行权。审批过期使用数据库时间，重启不重新计时。

等待与动作数据

一 Run 一个当前等待点；决定绑定提案版本和摘要。reconciliation 等待允许无截止时间，始终先核对既有结果。

效果核对与回执

  • 已生效只补回执；未知效果进入待核对。
  • 新增效果前复查当前权限、原提案和产物。
  • 课堂效果由唯一 Action ID 约束，普通远端非幂等调用保持待核对策略。
