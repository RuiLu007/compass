## 一句话描述

持久化 Run/Step/Attempt、事件与 Checkpoint，实现跨进程 Resume、人工审批等待、暂停和取消。

## 背景

M4 可以受控执行分析与工具。审批与长任务跨越请求和进程，必须从已完成的步骤继续并避免重复产生业务效果。

## 关键决策

- 持久化原 Run 的状态、Step/Attempt、事件和 Step 边界 Checkpoint。运行数据与状态转换由 Agent 管理。
- 将 M3 的等待点和 M4 的动作提案接入持久审批。暂停、取消和恢复沿用原 Run，以稳定 Action ID 核对已提交的受控动作。
- 本课交付从已保存位置恢复的能力。M6 负责失联发现、Queue/Worker 接管和事件续流。

## 课堂演示与验收

- 将 Retail 分析提案停在待审批位置，释放执行资源后重启 Agent。提交有效审批并从原 Run 的 Checkpoint 接续。
- 核对已完成步骤被复用。注入重复审批和动作回执中断，检查状态、Action ID 和业务效果计数。
