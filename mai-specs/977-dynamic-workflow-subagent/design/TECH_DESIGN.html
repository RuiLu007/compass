动态 Workflow 与 SubAgent

在 Chat 中完成探索，把模型编排保存为工具，并让后续模型用新参数调用。

工具装配资产执行与保存

工作流如何成为工具

可执行资产

字段运行职责
资产 ID、用户、工作区固定函数名称和授权作用域
名称、说明与 JSON Schema供模型选择函数并生成输入
JavaScript、摘要、执行契约复跑同一版本并核对源码完整性
启用状态与管理版本在后续 Chat Run 生效
// 示例是一个脚本体。模型在函数调用里填写 args。
const first = await agent("sub_agent", { prompt: "核对时段 " + args.window });
const [detail, review] = await parallel([
  () => agent("sub_agent", { prompt: "拆解 " + first.answer }),
  () => agent("sub_agent", { prompt: "复核 " + first.answer }),
]);
return { status: "ok", result: { detail: detail.answer, review: review.answer } };

沙箱、宿主与持久运行

  • 脚本的宿主入口校验子任务参数和派发数量。父 Run 控制预算、权限、超时与取消。
  • 确认保存使用 Agent 的现有资产生命周期。新 Run 从个人资产加载声明，执行前复验启用状态与授权。
  • 子任务用现有 Step/Attempt 记录归属。0012 只扩展工作流资产的说明和参数字段。
