## 1. 背景与目标

月度经营分析可以将库存和转化诊断交给不同 SubAgent 同时推进。分析员需要了解各项子任务的进度，并在出现异常或需要核对结论时，打开其中一项查看它实际执行过的步骤。

本课沿用第 19 课的 Run、Step、Attempt 和 Checkpoint，以及第 20 课的用户可见事件流。父 Run 向 Child Run 交接最小必要上下文，Chat 在父任务的分析过程里显示子任务状态与摘要，并提供单个子任务的授权执行轨迹。

## 3. 总体业务流程

父 Run 为库存与转化诊断生成各自的交接信息。两个 Child Run 并发推进，独立记录进度和结果。主对话在「分析过程」中更新各自的卡片。用户展开一张卡片时，服务端核对父子归属和当前权限，返回所选子任务可见的执行历史与后续进度。父 Run 消费子任务结果或明确的失败状态，最终仍由父 Run 的 `finalAnswer` 控制主对话切换。

## 8. 验收标准

### AC-01｜两个 SubAgent 并发，轨迹独立

**关联**　FR-01、FR-02、FR-03、BR-01、BR-02

- **Given**　月度经营分析可独立检查库存与转化，各子任务有可核对的输入范围和工具调用。
- **When**　同时启动两个 Child Run，让步骤交错完成并展开库存卡片。
- **Then**　两者的执行时间有重叠，卡片按各自 Run 更新。库存详情从启动到当前状态按顺序展示获准事件，只包含库存任务的步骤、调用和可见结果。两个子任务的输入与预算可核对。

### AC-02｜下钻和重连沿用当前权限

**关联**　FR-03、FR-04、BR-03、NFR-01

- **Given**　Child Run 的工具结果包含授权摘要和受限字段，另有不同租户或工作区的 Child Run。
- **When**　合法用户打开卡片并断线重连，再测试错配父子 ID、跨租户读取以及撤销详情访问权限后的续接。
- **Then**　合法用户续收原子任务的事件且无重复。错配和越权请求无可见轨迹，页面清除已失去权限的详情。响应载荷中无受限字段。

### AC-03｜子任务结束与父回答独立

**关联**　FR-02、FR-04、BR-02、BR-04

- **Given**　父 Run 同时展示两个 Child Run。
- **When**　一个子任务输出自己的最终回答，另一个失败，随后由父 Run 输出最终回答。
- **Then**　两个卡片分别显示各自终态与可见摘要。父过程在父回答阶段自动折叠一次。用户重新展开后仍能查看授权轨迹及对应失败原因。

## 月度分析的生命周期与恢复

月度分析跨销售、营销、库存和财务阶段。分析师暂停任务，次日恢复时部分数据已更新，且库存明细访问权可能已撤销。

沿用首批父子 Run 和 Chat 轨迹需求。第 24 课提供单步预算与压缩，本课负责跨步骤进度与恢复。

## 功能范围与验收场景

### 状态与阶段摘要

History 保留事件，State 维护目标、进度、约束和待办，Summary 按阶段提炼事实，Artifact 保存大结果。跨会话 Memory 仅接纳有来源、适用范围和有效期的可复用信息。

**AC-04**　完成销售阶段后暂停，检查摘要中数值能回到原始结果，下一阶段从待办继续，新的独立会话仅可取回有权复用的记忆。

### 压缩与遗忘

预算超限、阶段完成或任务切换时压缩。保护指标口径、关键值、失败记录、待办与引用；将过期和重复项移出活跃上下文，记录归档原因与重载条件。

**AC-05**　以同一月度任务比较滑动窗口、阶段摘要与按价值保留，记录完成率、关键事实保留、重复查询和 Token；丢失约束的摘要不得替换原状态。

### 恢复与漂移

恢复前核对任务目标、最新权限、数据版本和已完成操作；失效证据转入补查，冲突事实标记待核。对子任务返回值验证来源和目标再汇入父任务。

**AC-06**　在写报告后中断并撤销明细权限。重复恢复应跳过已完成写入，剔除失权明细及派生摘要，重查变化的数据；模拟子任务返回冲突值时标记差异并保留两方引用。
