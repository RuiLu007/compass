## 一句话描述

登记第 25 课首批需求：并发 Child Run、父子上下文交接和分析 Chat 内的授权执行轨迹下钻。

## 背景

第 20 课建立可重连的用户可见运行事件流。月度经营分析中的库存与转化可由不同子任务并发推进，用户需要区分各任务的状态，并能按权限查看单条执行轨迹。

## 关键决策

- 父 Run 把库存和转化分析交给独立的 Child Run 并发执行，每个子任务只接收完成自身目标所需的上下文、数据权限和预算。
- 分析 Chat 先展示子任务的状态和摘要，再按当前访问权限读取选中 Child Run 的执行轨迹。复用第 20 课的事件展示与续接契约。
