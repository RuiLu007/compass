# 第 22 课企业经营语义治理验收

本计划采用 standard 规格，覆盖 AC-01 至 AC-16。用户本轮将治理人工作业耗时对照从验收范围中移除。课程效果验收保留业务域、语义识别、同名消歧、SQL 语义正确率和复杂任务五项目标，以及权限用例全部阻断的要求。[需求简报](../BRIEF.md) · [产品验收标准](../spec/PRD.md#8-验收标准) · [教学内容约定](../spec/SEMANTIC_CONTENT_PRD.md) · [实施与兼容性](../design/TECH_DESIGN.md#5-实施切片与验收) · [项目测试模板](../../_templates/TEST_PLAN.tmpl.md)

## 三类资产与口径选择

工作台按类型筛选实体、术语和指标，定义保存后生效。同一账号有多个可见口径时，分别传入成功支付和净额候选可解析到各自版本；只给出含糊称谓，会进入原会话选择。另覆盖无关候选 ID、缺失绑定、固定清单回看及越权访问。教学包升级须保留历史版本、关系与人工修订；重复升级不增加版本。

下文的冻结题集和成绩记录各代发布当时的判分规则。旧题集里按部门预选口径的结果仅用于历史对照。
