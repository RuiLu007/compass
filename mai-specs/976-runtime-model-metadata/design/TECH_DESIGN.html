模型目录与配置

复用精确目录条目的输入与输出上限。共享总窗口、temperature 和 top_p 由管理员核实并配置。未知值保留为空。

部署配置与版本

保存沿用平台权限、操作幂等与预期版本。导入快照固定目录键和 SDK 版本，显式刷新后生效。配置变化推进绑定版本。

模型调用与错误回传

def resolve_max_tokens(requested, deployment_default, fallback):
    if requested is not None:
        return requested
    if deployment_default is not None:
        return deployment_default
    return fallback

后续上下文工程与输入框

  • 按实际路由模型计算预算，每次工具回填后重新估算，以完整历史轮次为单位裁剪。
  • 重放沿用原账本，新调用核验绑定版本。Agent Runtime 可根据上游超限错误重建请求。
  • Web 读取可见模型的有效限额，通过会话预算接口估算草稿长度。切换模型刷新额度，Agent Runtime 提交时重新评估上下文预算。
