## 关键发现

- LiteLLM 目录提供模型和能力探测，当前 CatalogItem 与 Runtime ModelSpec 未提供逐模型窗口、输入或输出上限及默认生成参数。
- 常规分析和受控自治的 max_tokens 分别固定为 8192 和 2048。生成请求默认为 8192，通用上限 32768。Runtime 上下文检查使用 512 条消息与 192 KiB 消息大小。
- 受控自治可按 Provider 绑定配置输入、输出 token 和成本预算，源码和环境模板默认配置为空。
- Provider 支持 SDK 连接参数透传，当前缺少 temperature、top_p 等结构化默认值及统一覆盖规则。检查范围为工作区源码和配置模板。
