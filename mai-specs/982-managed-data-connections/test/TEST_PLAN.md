## 业务用例

### TC-01 默认初始化、保存和刷新

- 关联需求 AC-01、AC-03。
- 前提为准备好 Retail 发布库和只读账号。创建同一租户下两个工作区，初始化仅绑定经营总部。
- 平台管理员打开经营总部的数据连接页，测试默认连接。改 Retail 租户 ID，密码留空保存，刷新后检查新值和密码状态。再运行初始化，刷新检查配置保留，恢复 Retail 租户 ID 后重测。
- 预期首次打开可见默认配置，正确绑定测试通过。保存持久化，密码输入留空且已有凭据可用。重复初始化保留已保存版本。另一工作区首次打开显示待配置。
- 以 Playwright 页面观察、API 状态和初始化命令退出结果记录。

### TC-02 异常与并发保存

- 关联需求 AC-01、AC-02、AC-05。
- 在已绑定工作区的两个页面加载同一版本。先保存错误 Retail 租户 ID，测试后检查安全提示。另一页提交原版本并检查冲突。刷新后用错误密码保存并测试，重新录入有效密码恢复。对允许列表外端点尝试保存。
- 预期测试可区分身份或租户不可用与连接失败。旧版本保存返回冲突且配置保持新版本。允许范围外目标被拒绝。成功与失败响应均受缓存保护且只返回安全字段。
- 检查页面及浏览器响应。需要核验驱动异常泄露时只做敏感字段断言，避免把驱动原始响应写进报告。

### TC-03 管理权限与表单可用性

- 关联需求 AC-01、AC-05。
- 分别以平台管理员、租户管理员打开工作区页。确认租户管理员的联系提示，直接调用管理接口应被拒绝。使用平台管理员会话但省略 CSRF 发出保存请求，验证服务拒绝。缩至手机视口，用键盘进入字段和保存、测试控件。
- 预期平台管理员可管理，租户管理员不读取或修改连接。缺 CSRF 保存失败。表单字段有可访问标签，窄屏可使用。

### TC-04 分析使用工作区配置

- 关联需求 AC-03、AC-04。
- 以具备分析权限的用户分别进入已绑定的经营总部和未绑定的华东区域。发起两周渠道与商品对比。检查真实查询事件、结果及产物，并用受限账号执行独立 SQL 核对数据。
- 预期已绑定工作区可见并执行 Retail 工具，观察值与对照 SQL 一致。未绑定工作区保留普通 Chat，同一模型上下文不提供 Retail 工具。
- 以 Playwright、真实 BFF SSE 事件、受限数据库对照查询记录。

所有写操作限本次专用 Web 与 Agent 库。验收结束后关闭专用进程并清理临时应用库，Retail 源库仅执行查询。

## 每工作区多连接追加验收

保留上方单连接实现的历史结果。追加验收以当前 PRD 的多连接、PostgreSQL/MySQL、默认 Retail、工作区隔离及分析规则为准。复用教学平台管理员和分析用户，独立准备 Web 与 Agent PostgreSQL 应用库，以及本机 MySQL 8.4 临时容器。Retail 与通用 PostgreSQL 使用已发布源库的只读账号。MySQL 使用临时只读账号。

### TC-05 迁移和重复初始化保留默认 Retail

- 关联需求 AC-03、AC-09。
- 在 Agent 应用库 0005 保存已有 Retail 配置及版本，再升级至 0006 并执行初始化。打开经营总部的数据连接页，核对默认连接和版本，运行测试。
- 预期旧配置迁移为当前工作区默认 Retail，已有凭据可用，版本继续保留。重复初始化保持已迁移默认配置和后来添加的通用连接。
- 使用真实应用库迁移、浏览器和新旧 API 读取结果记录。

### TC-06 管理并独立测试两种数据库连接

- 关联需求 AC-07、AC-08。
- 平台管理员在默认 Retail 同一工作区从页面新增通用 PostgreSQL 和 MySQL，刷新确认三条记录同列。分别测试两种数据库。仅修改 MySQL 显示名并留空密码，保存后重测。分别用错误的 PostgreSQL 和 MySQL 密码保存和测试，检查安全反馈后恢复。每次编辑只影响对应连接的版本和可用性，默认 Retail 保持原配置。
- 预期各连接具有独立标识、版本与测试反馈。两种驱动均通过真实连接测试。错误密码反馈在对应连接行显示，响应和日志保护凭据。更改 MySQL 后，其余记录保持原状。
- 使用浏览器操作、管理 API 的安全响应及独立 MySQL 可连接性检查。

### TC-07 工作区隔离和默认分析回归

- 关联需求 AC-04、AC-05、AC-08、AC-09。
- 从其他工作区列出连接，以其租户与工作区范围请求原工作区连接标识的更新和测试。确认默认 Retail 和两条通用连接仍留在原工作区。
- 分析用户在经营总部发起原 Retail 渠道与商品分析。另一个工作区只配置通用连接后发起同一分析。以受限账号独立查询并比对经营总部的 CSV。
- 预期其他工作区无法读取、测试或修改经营总部的连接。经营总部分析使用默认 Retail，结果与独立查询一致。只配置通用连接的工作区可完成普通 Chat，Retail 工具保持关闭。
