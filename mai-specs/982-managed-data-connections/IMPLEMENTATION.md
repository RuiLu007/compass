## 多连接扩展

- 0006 将旧记录事务性迁移为「本地 Retail」，保留工作区、凭据密文和配置版本。工作区列表按独立连接 ID 管理 PostgreSQL 和 MySQL 记录。现有 Retail 分析和旧管理 API 继续解析同一默认连接。
- 通用 PostgreSQL 与 MySQL 按引擎使用各自驱动探测，连接名及配置按工作区保存。密码密封绑定连接，测试只返回安全状态。
- 本机 Agent 库已备份并升到 0006。新列表读到迁入的默认 Retail，实际连接测试与本机 smoke 通过。
- Playwright 验证默认 Retail、普通 PostgreSQL 与 MySQL 8.4 在同一工作区并存，覆盖新增、编辑、刷新、坏密码重试、重复 seed 和跨工作区请求拒绝。已有分析仍查询默认 Retail，CSV 与独立 SQL 一致。仅有通用连接的工作区保持普通 Chat。
- Agent PostgreSQL 27 项集成测试通过，包含 0005 到 0006 的原生及增量 SQL 升级、原密文解密、备份恢复和配置隔离。工程检查、构建、SQL 及契约生成一致性通过。独立 Compose 供应并迁移 Web/Agent，运行态 smoke 和默认 Retail 探测均通过。
