## 多连接扩展复评

方案可实施。重点校对默认路由、凭据搬迁和 MySQL 传输选项。

- 旧记录在 0006 中事务性转为默认 Retail，沿用原密封用途和版本。新增普通连接使用独立 ID 及密封用途，分析仅解析默认 Retail。受管迁移验收核对旧密文仍可用和普通记录相互独立。
- 两种数据库使用各自驱动和固定探测。MySQL 的证书校验模式要求 TLS 与主机名匹配。测试端点沿用部署允许列表，服务只返回安全分类。
- 列表、编辑和测试共用工作区授权。连接 ID 参与所有查找条件，旧接口与新接口操作同一默认记录，版本更新比较条件一致。
