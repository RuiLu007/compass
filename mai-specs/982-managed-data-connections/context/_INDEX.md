## 关键发现

- Web 的「管理端 → 数据与语义 → 数据连接」已有导航入口，页面仍为空壳。首期沿用这个入口，管理员可查看、编辑和测试本地 Retail PostgreSQL 连接。
- 现有 Retail 分析工具从 Agent 部署环境读取工作区绑定与只读 DSN，发布版本、数据摘要、租户和 schema 还有固定约束。运行时改为根据授权工作区读取数据库中的连接配置，并继续使用受限只读身份。
- 按现有运行配置归属，将连接和工作区绑定存入 Agent 应用数据库，由 Web 管理端经服务接口操作。连接凭据仅在服务端使用，页面展示脱敏信息。
- 本地 Retail 准备完成后，初始化应登记一条可用的默认连接。重复初始化保留管理员已保存的配置。验收覆盖管理端连接测试和已授权工作区通过现有分析入口执行只读查询。Retail 尚未准备时，管理端应显示连接不可用及可处理的原因。

## 开放问题

- 技术设计阶段确定默认连接对应的本地 Retail 发布库和受限账号，并明确首次初始化与已有部署配置的迁移方式。
- 技术设计阶段明确连接管理权限以及默认连接的工作区绑定规则。
