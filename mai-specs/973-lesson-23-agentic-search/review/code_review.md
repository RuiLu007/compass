# 第 23 课代码审查

2026-11-22。审查范围：默认通用 Loop、工具层来源控制、Verify、final_answer、引用、前端正文边界及 Home 单课分发。按用户要求在实施中持续复查。

## 架构结论

新协议通过既有 Loop 的 prepare / accept / dispatch 接入，校验反馈使用 RepeatStep。语义 Review 是主模型在同一 Loop 中的一步，关闭工具并计入预算。注册的结果适配器负责理解工具结构；通用校验器处理来源、目标、计算和交付。来源授权复用现有 owner 接口。没有新增搜索开关、专用搜索 Agent、案例关键词分支或专用调度框架。

## 交付边界

新工具访问拒绝回到循环；已经进入上下文的来源撤权沿既有权限设施终止 Run。模型审阅仍可能遗漏业务问题，当前工程检查与真实业务结果分别记录。历史课堂金标准和重复运行成功率沿原口径核对，本轮结果见 [验收记录](../test/ACCEPTANCE.md)。

源码检查、Agent／Web 类型与测试、PostgreSQL 交付／恢复、实际页面和离线阅读器都纳入本轮验证。跳过项与未覆盖项不计通过；完成状态以验收记录中的本轮结论为准。
