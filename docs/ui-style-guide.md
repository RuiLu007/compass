# Compass UI 样式规范

适用于 Compass 的页面、弹层、分析消息、组件和交互状态。Web 产品界面以 [设计变量](../apps/web/src/app/ui-system.css)、[共用组件](../apps/web/src/components/ui)和产品内的 [体验指南](http://127.0.0.1:8100/guide) 为准。课程官网沿用相同的可读性和交互要求，品牌页面的布局和视觉细则见 [官网说明](../apps/home/README.md)。

## 基础设计

| 项目     | 规范                                                                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 颜色     | 暖白 `--canvas` 承载页面，白色 `--surface` 承载卡片。正文、辅助信息和主操作分别使用 `--ink`、`--muted`、`--primary`。状态用文字说明，配合图标和语义颜色。 |
| 排版     | 正文 16 px，控件 14 px，辅助信息 12 px，卡片标题 18 px。正文行高约 1.55，代码使用独立的等宽字族。                                                         |
| 间距     | 使用 4 px 基准，按 4、8、12、16、20、24、32 px 组织。标签与控件通常间隔 8 px，同组信息间隔 12 px，卡片内边距通常为 20 px。                                |
| 边界     | 控件圆角 8 px，卡片圆角 14 px。容器用浅色边框区分，输入边界和焦点使用对比度更高的变量。                                                                   |
| 响应式   | 内容在 390 px 宽度下可完整阅读，表单和元数据按空间换行。表格与代码长行在自身容器内滚动，页面维持纵向阅读。                                                |
| 可访问性 | 常规文字与背景对比度至少 4.5:1。交互元素保留键盘焦点环，触屏操作区至少 44 × 44 px。只含图标的操作提供可访问名称。                                         |
| 动效     | 操作反馈优先用约 140 ms 的短过渡。请求进行时同时提供动态图标和文字，遵循 `prefers-reduced-motion`。                                                       |

## 组件与状态

| 组件 | 使用约定                                                                                                               |
| ---- | ---------------------------------------------------------------------------------------------------------------------- |
| 卡片 | 以标题和可选说明开头，中间放结果或表单，底部放同一任务的操作。日期、版本等字段用标签和值成组展示。                     |
| 按钮 | 每个操作区突出一个主操作。次要操作使用描边或弱化样式，破坏性操作使用危险样式。等待响应时显示进行状态并防止重复提交。   |
| 表单 | 每个输入有可见标签。帮助文字和错误放在字段附近并建立程序关联。提交失败时保留输入，提供可执行的恢复动作。               |
| 反馈 | 成功和异步进度使用状态区，可立即处理的错误使用告警。空状态说明可用操作，禁用态说明用户可以如何恢复。                   |
| 折叠 | 采用可聚焦的标题行与统一方向图标。次要详情默认收起，需要用户审阅的内容可默认展开。                                     |
| 弹层 | 有明确的标题、确认与取消操作，支持 Esc、键盘焦点限制与关闭后恢复焦点。对写入资产等决定，先提供审阅信息，再由用户确认。 |

## 代码展示

多行源码使用 [UiCodeBlock](../apps/web/src/components/ui/code-block.tsx)。工具栏左侧显示脚本名或入口标识及语言，右侧提供自动换行和复制。等宽正文保留空格与缩进，初始按原始行显示。代码区高度上限为 20 rem，内部支持键盘滚动。切换换行只影响显示，复制使用原始字符串并反馈结果。

生成的源码按纯文本渲染。代码面板承载阅读、选取与复制，执行入口作为业务操作单独呈现。工作流脚本与查询结论分别折叠，保存确认区位于详情之后。

## 演示与维护

登录产品后进入「体验指南」。页面直接演示设计变量、按钮及反馈、代码面板、表单错误、取消与确认。演示确认只改变示例状态。

页面开发先复用已有变量和组件。新增通用变体时同步更新本规范和演示页。交付前核对桌面、窄屏、键盘、请求进行中及失败状态，涉及代码时检查长行、换行和复制。课程展示和产品评审可直接使用体验指南对照。

## 执行过程

Chat 和体验指南共用 `UiExecutionTimeline`。运行过程默认折叠，单行展示最近更新的事件、状态和用时。展开后，思考、旁白、工具、工作流、技能和子任务按开始时间排在同一列。新事件追加，已有事件按稳定 ID 更新。列表在底部时跟随新内容，向上阅读时保留滚动位置。

事件行使用图标、中文类型和一行内容。思考展示模型提供的正文，工具展示具体名称。带详情的行支持键盘独立展开。获授权的查看者可读取正文和脱敏后的工具入参、结果。输入输出使用 `UiCodeBlock` 的局部滚动、换行及复制。并行分组、依赖、MCP 来源和 Sandbox 等执行环境在事件详情中呈现。等待和失败使用文字与语义颜色，减少动态效果模式保留文字状态。

收到完成状态后自动收起过程，显示“已完成”和总用时，手动重新展开可回看。焦点位于过程内部时回到折叠按钮。体验指南提供进行中、成功、失败、等待、取消和中断状态。

## 持久会话与执行确认

会话输入区贴在底部，模型、附件和发送按钮与输入框底边留一档间距。支持背景模糊的浏览器在正常高度下让消息滚到半透明输入框后方，并保留末条消息完整露出的滚动空间。极矮窗口与启用减少透明度的环境使用实色输入框。

已保存工作流在 Workflow 页面查看、改名、启停、删除和导出脚本。删除须经弹窗确认，默认聚焦取消，删除后焦点回到列表标题。启用的动态工作流可按当前工具清单由模型自主调用。旧执行契约显示管理和导出说明。课程案例按钮填入普通问题，焦点回到输入框。

分析会话使用稳定 URL，首次发送后进入服务端 Session。侧栏列表占用分组切换与工作空间入口之间的可用高度，会话标题单行显示，溢出时截断，加载更多后保留已加载项。历史消息、完整执行过程、图表和保存邀请一次恢复，已保存正文不重播打字动画。SSE 断线显示重连状态并保留内容。

进入分析页、会话变更和切回浏览器标签页时刷新会话列表。待生成的自动标题通过单条会话查询更新。

会话标题使用整行可用宽度，溢出时显示省略号。鼠标持续悬停时，长标题平移一次并停在末尾，移开后恢复开头。开启减少动态效果时可通过标题提示查看全文。三点菜单浮在会话行右侧，悬停或键盘聚焦时显示，触屏可以直接点按。改名弹层预填标题，删除弹层默认聚焦取消。自动生成的标题直接更新会话行。

暂停和继续位于分析过程同一行，停止任务位于输入区。`.durable-approval` 在原轮次内展示安全摘要、截止时间及当前状态。操作沿用现有焦点样式和禁用规则，请求期间显示提交状态。暂停与停止遇到版本竞争时读取最新状态并有限重试，审批冲突刷新原卡片。待核对保持独立说明，完成取消后执行过程中的工具状态同步更新。窄屏审批按钮换行，产物下载保留原文件名。工作流保存卡展示编排、工具参数契约、试跑入参与结论，从持久投影恢复保存状态与名称，到期后显示邀请失效，保留原分析与脚本。
