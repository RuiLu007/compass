**经营报告**

- 确认报告读者、要作的决定、期间、比较基准和数据截至时间。
- 先写下支撑决策需要回答的几个问题，查明各自的术语、实体、关联、指标定义和正式来源。
- 按信息缺口选择工具，前置事实会改变样本或日期时先核实它。
- 对支撑主结论的异常做交叉核验。
- 以正式指标回执确定量级，再选能检查该解释的独立材料，如业务事件、对照群体或生效文档。
- 核对来源是否共用同一底表，记录版本、粒度及分母差异。
- 遇到冲突，先重算或对齐范围；确实无法消解时把剩余影响写入报告。
- 开篇写本期最重要的变化、影响及行动。
- 正文按问题呈现基准、本期、差额、证据和仍成立的替代解释。
- 行动说明优先对象、复核时点和判断标准。
- 摘要、正文和下载稿共用一组已验证的数字；保留来源、数据缺口与可复现的查询范围。
