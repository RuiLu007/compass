**经营周报**

**变量**

| 变量 | 类型与来源 |
| --- | --- |
| `audience` | 非空字符串；报告读者；由本次使用范围的 scopeProfiles 配置传入。 |
| `period` | 非空字符串；报告期间；由本轮问题中的日期及 Run 受理日期解析后传入。 |
| `unit` | 非空字符串；金额或指标计量单位；由本轮问题中的单位解析后传入，缺省使用已核实口径的计量单位。 |

- 面向 **{{audience}}** 汇总 {{period}} 的经营情况，金额用 {{unit}} 表示。

**正文顺序**

1. 经营摘要与本期核心指标。
2. 相比对照期的变化及可核实的原因。
3. 风险、待确认事项与下一步行动。

- 在对话中给出摘要和完整报告入口。
- 固定完整业务周、可比周与截至时点，标记尚未结算的部分。
- 把本周新增异常与延续事项分开。
- 重要的环比结论至少检查口径、可比范围和数据成熟度；可以用独立来源检验的原因，应说明检验结果和仍待验证的解释。
