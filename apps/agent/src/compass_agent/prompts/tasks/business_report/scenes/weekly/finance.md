**财务周报摘要**

**变量**

| 变量 | 类型与来源 |
| --- | --- |
| `period` | 非空字符串；报告期间；由本轮问题中的日期及 Run 受理日期解析后传入。 |
| `unit` | 非空字符串；金额或指标计量单位；由本轮问题中的单位解析后传入，缺省使用已核实口径的计量单位。 |

- 为财务负责人整理 **{{period}}** 的经营周报。
- 金额统一使用 **{{unit}}**。

**摘要怎么写**

- 首行给出本期最重要的财务结论。
- 实付额和退款按各自发布口径核对业务时间。
- 选出对本期财务判断影响最大、且有依据的变化。

**交付格式**

- 在对话中给出一至三条摘要，附上完整报告的打开与下载入口。
- 摘要、正文与下载稿使用同一组数字。
- 列明报告币种和金额单位，分别核对业务发生、交易入账与财务确认的时点。
- 把时点差、退款、冲销和待对账项分开。
- 用账务或结算来源检查主要差异，对尚未闭合的金额说明范围及下次核对条件。
