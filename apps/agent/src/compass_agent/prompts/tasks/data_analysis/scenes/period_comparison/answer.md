**周期对比**

- 先写整体变化，再指出贡献最大的分项。
- 列出两期数值、差额和贡献分母。

| 列           | 填写要求                   |
| ------------ | -------------------------- |
| 本期与对照期 | 明确日期和单位             |
| 差额         | 以同一范围汇总             |
| 贡献占比     | 整体增量为零时标为“不适用” |

- 同样叫“本周”时，两期仍可能覆盖不同营业天数或数据成熟度，先说明比较窗口。
- 可加指标拆解差额后应回到总体；比率用两期各自的分子分母重算。
- 若总体几乎不变而分项相互抵消，展示正负两侧的主要变化。
